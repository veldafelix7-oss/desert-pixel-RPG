# Prototipe Android — gerak dan combat

## Cara pasang dari HP
1. Di bagian **Assets**, unduh **desert-pixel-rpg-0.1.0-debug.apk**, bukan Source code ZIP/TAR.
2. Buka file melalui Unduhan/Downloads, lalu pilih Instal.
3. Bila Android meminta izin pemasangan dari Chrome atau File Manager, izinkan hanya sumber yang kamu gunakan dan percayai; matikan kembali setelah selesai. Jangan mematikan Play Protect.
4. Buka **Desert Pixel RPG**. Game memakai layar mendatar. Tekan Mulai Petualangan dan ikuti petunjuk.

Android 6+ diperlukan. Target pengujian pengguna: Tecno Spark 20C. Performa dan perilaku native belum diuji pada perangkat tersebut.

## Isi prototipe
Petarung, oasis kecil, joystick, serangan sesuai arah hadap, dua skill, dodge, kalajengking, quest latihan, potion, NPC perbaikan, minimap, pengaturan HUD, bahasa Indonesia/Inggris, pilihan batas 30/60 FPS, serta autosave lokal. Tidak membutuhkan akun atau server game; aset sudah berada di APK untuk bermain offline.

**Ini APK debug untuk pengujian, bukan game lengkap atau rilis Play Store.** Dunia besar, class lain, crafting, rumah, tunggangan, dan festival belum tersedia. Nama/logo/visual masih sementara.

## Perhatian untuk save dan update
Save browser preview tidak otomatis pindah ke APK. Menghapus data atau uninstall dapat menghapus seluruh progres dan cadangan lokal. Signing key debug dapat berbeda pada build berikutnya; jika update ditolak karena tanda tangan berbeda, jangan uninstall jika ingin mempertahankan save. Signing tetap untuk distribusi berkelanjutan belum disiapkan.

Build APK dan pemeriksaan tanda tangan otomatis tidak menggantikan pengujian di HP. Jika instalasi atau permainan gagal, kirim screenshot pesan error tanpa informasi sensitif.
